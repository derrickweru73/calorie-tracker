# Calorie tracker application

## Project Overview
 A modern, responsive, and lightweight client-side Calorie Counter dashboard constructed using semantic HTML5 structures, Tailwind CSS utility layout frameworks, and vanilla ES6+ JavaScript.

It helps users:
  Help It Gives the UserCalculates Personalized Goals: Estimates Daily Energy Expenditure (TDEE) based on age, weight, and activity level.Simplifies Food Logging: Uses barcode scanners and verified databases to make entering meals fast and accurate.Balances Macronutrients: Displays visual charts splitting daily intake into proteins, carbohydrates, and fats.Provides Accountability: Sends reminders to log meals, helping users stick to their lifestyle changes.Tracks Hydration: Includes water logging features to ensure proper hydration alongside nutrition.Reveals Eating Patterns: Shows historical trends, helping users identify which foods cause energy crashes or overeating.
--- 

## Problems it solves
-Mindless Eating: People often eat without realizing how much energy they consume. Tracking forces awareness.-Misjudging Portion Sizes: Humans are notoriously bad at estimating food weight. Apps standardize measurements.-Hidden Ingredients: Restaurant meals and processed foods contain hidden fats and sugars. Databases expose these.-The "Nutritional Blindspot": It is hard to know if you are getting enough protein, vitamins, or fiber just by -looking at a plate.Forgotten Calories: Liquid calories from coffees, sodas, and cooking oils are frequently forgotten but caught by logs.Inconsistent Progress: Without data, it is impossible to know why a weight loss or muscle gain  is happening   
 

## Features
- Dynamic Food Log Management: Add, view, and instantly remove logged meal items.
- Asynchronous Fetch API Integrations: Simulates live production data lookups via async request streams.
- Persistent Cookie-Based Storage: Retains daily logging history across browser tab closures or reloads using     secure client-side cookie string parsing routines.
- Automated Total Math Operations: Instantly calculates and synchronizes cumulative calorie data directly across display views.
- System Purge Controls: Built-in reset configurations to clear state profiles and logs instantly.
